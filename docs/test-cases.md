# Класи еквівалентності та граничні значення

## Параметр «Пароль» (довжина і склад)

| Клас | Діапазон | Граничні значення | Результат |
|---|---|---|---|
| Недійсний: закороткий | довжина 0 … 7 | 0; 7 | ValidationException |
| Дійсний | довжина 8 … 64 (є літера і цифра) | 8; 64 | Прийнято |
| Недійсний: задовгий | довжина > 64 | 65 | ValidationException |
| Недійсний: склад | немає літери або немає цифри | 12345678; abcdefgh | ValidationException |
| Недійсний: відсутній | null | – | ValidationException |

## Параметр «Назва нотатки» (довжина)

| Клас | Діапазон | Граничні значення | Результат |
|---|---|---|---|
| Недійсний: порожня | довжина 0 або лише пробіли | 0; "   " | ValidationException |
| Дійсний | довжина 1 … 100 | 1; 100 | Прийнято |
| Недійсний: задовга | довжина > 100 | 101 | ValidationException |

## Параметр «Заповнення сховища» (використано / ліміт)

| Клас | Діапазон | Граничні значення | Результат |
|---|---|---|---|
| Недійсний ліміт | ліміт ≤ 0 | −1; 0 | ValidationException |
| Норма | < 80 % ліміту | 0; 799 з 1000 | Normal |
| Попередження | 80 % … 100 % включно | 800; 1000 з 1000 | Warning |
| Перевищення | > 100 % | 1001 з 1000 | Exceeded |
